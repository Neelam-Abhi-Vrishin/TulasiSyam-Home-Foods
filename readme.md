
# TulasiSyam Home Foods

**Homemade Taste. Made With Care.**

A responsive, single-page informational website for TulasiSyam Home Foods, a homemade traditional Indian sweets and savouries business based in Gajularamaram, Hyderabad, Telangana, India.

## About the Website

The website introduces the business, showcases its products, shares ingredient information, and helps customers contact the business.

It is built using:

- HTML5
- CSS3
- Vanilla JavaScript

No frontend frameworks or build tools are required.

## Add Your Assets

Place your original business logo in `assets/logo/` and your actual product photographs in `assets/products/`.

Ensure that the filenames and file extensions match the paths used in `index.html`. If an image is WebP, retain its `.webp` extension unless you convert it to another image format.

## Run Locally

1. Open the project folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension for a convenient local preview.
3. Test the navigation, ingredient controls, contact links, and image loading.
4. Use browser Developer Tools to inspect the website at different viewport widths.

## Deployment

This project is designed for static hosting, including GitHub Pages.

After testing the website locally:

1. Create a GitHub repository.
2. Commit or upload the project files while preserving their folder structure.
3. Open the repository's **Settings → Pages**.
4. Configure GitHub Pages to publish from the appropriate branch and root folder.
5. Open the published website and check its layout, links, and images.

## Important Notes

- This is an informational website, not an online store.
- It does not provide shopping carts, checkout, payment processing, or customer accounts.
- Keep contact details and external links accurate.
- Do not publish unverified claims, certifications, customer reviews, or ratings.
- Test the deployed website before considering it complete.
